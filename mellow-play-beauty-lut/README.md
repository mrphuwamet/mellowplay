# mellow-play-beauty-lut

ไฟล์ฟิลเตอร์แต่งภาพสำหรับ LumaBooth — ได้ไฟล์จริงมาใช้เลย ไม่ต้องเปิดโปรแกรมแต่งภาพ

## ไฟล์ที่ใช้ได้เลย

**`Mellow-Play-Soft-Beauty.cube`** — สร้างไว้ให้แล้ว เอาไปใช้ได้ทันที

## อยากรู้ก่อนว่า LUT ทำอะไรได้/ไม่ได้

LUT (ไฟล์ `.cube`) คือตารางแปลงสี **ต่อพิกเซล** เท่านั้น — เปลี่ยนสีให้อุ่นขึ้น ผิวดูนุ่มขึ้น แสงเงาดูสบายตาขึ้นได้ แต่:

- **ทำไม่ได้**: เกลี่ยผิว ลบสิว ปรับรูปหน้า ทำตาโต — พวกนี้ต้องขยับพิกเซล (เบลอ, บิดภาพ, AI retouch) ซึ่งไม่มี LUT ชนิดไหนในโลกทำได้ ไม่ว่าจะสร้างด้วยโปรแกรมไหน
- ถ้าอยากได้ผิวเนียนจริง ๆ ให้ไปดูที่เมนู **"AI Portraits"** ของ LumaBooth เอง (อยู่คู่กับ Effects & Stickers ในหน้าตั้งค่า) — อันนั้นคือฟีเจอร์ retouch จริง คนละเรื่องกับ Filter/LUT

สิ่งที่ไฟล์นี้ทำจริง (ปรับทีละขั้นด้วยสูตรที่เขียนไว้ใน `generate-lut.mjs`):
1. ยกเงาให้ไม่ดำจัด + กดไฮไลต์ไม่ให้ขาวโพลน
2. เฉพาะโทนสีผิว (เหลือง-ส้ม) ให้สว่างขึ้นนิดและลดความจัดสีลงนิด — ดูนุ่มขึ้นแบบไม่เปลี่ยนสีอื่นในภาพ
3. สีอื่นที่ไม่ใช่โทนผิว อุ่นขึ้นเล็กน้อยและสดขึ้นเล็กน้อย กันภาพดูจืดไปทั้งใบ

ทดสอบแล้วว่าทำงานตามนี้จริง (อ่านค่าออกจากไฟล์ `.cube` ที่สร้างจริง ไม่ใช่แค่เดาจากสูตร) — เงาไม่ดับ ไฮไลต์ไม่ขาวจัด ผิวสว่างขึ้นและนุ่มขึ้นทั้งโทนสว่างและโทนเข้ม สีอื่นไม่โดนหางเลข

## วิธีใช้ใน LumaBooth

จากที่เช็คได้ตอนนี้ LumaBooth รองรับ custom LUT (.cube) ทั้งจากหน้า Dashboard (อัปโหลดแล้วพรีวิวสดได้) และจากหน้า Settings → Filters ของตัวโปรแกรมเอง — เมนูอาจย้ายที่ไปบ้างตามเวอร์ชัน ให้หาคำว่า "Filters" หรือ "Custom LUT" แล้วอัปโหลดไฟล์ `Mellow-Play-Soft-Beauty.cube` เข้าไป

**แนะนำให้ลองพรีวิวกับรูปจริงก่อนใช้ในงานจริงเสมอ** — สีที่ "พอดี" ขึ้นกับแสงหน้างานด้วย ถ้าแสงอุ่นอยู่แล้วอาจรู้สึกอุ่นเกินไปนิดหน่อย

## อยากได้ลุคของตัวเอง ไม่ใช่สูตรนี้

ทางที่ถูกต้องและเป็นมาตรฐานวงการคือ **DaVinci Resolve** (ฟรี, มีให้โหลดบน Windows/Mac) — เปิดรูปตัวอย่าง ปรับสีด้วยหน้า Color จนพอใจ แล้วคลิกขวาที่คลิป → เลือก **"Generate 3D LUT"** จะได้ไฟล์ `.cube` ออกมาแบบเดียวกับไฟล์นี้เป๊ะ เอาไปใช้แทนหรือเสริมกันได้เลย

## อยากปรับสูตรนี้เอง

แก้ตัวเลขใน `generate-lut.mjs` ใต้ฟังก์ชัน `BEAUTY()` แล้วรัน:

```
node generate-lut.mjs
```

จะได้ไฟล์ `Mellow-Play-Soft-Beauty.cube` ตัวใหม่ทับของเดิม ไม่ต้องติดตั้งอะไรเพิ่ม (ใช้ Node เปล่า ๆ ไม่มี dependency)
