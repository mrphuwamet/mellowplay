# mellow-play-album-sync-gui

หน้าต่างง่าย ๆ สำหรับ `mellow-play-album-sync` — เลือกโฟลเดอร์ด้วยปุ่ม Browse แทนการแก้ไฟล์ `.env` เอง กดเริ่ม/หยุดแทนเปิด terminal

**เครื่องมือเดิม (`mellow-play-album-sync`) ยังใช้งานได้ตามปกติ** — ตัวนี้เป็นแค่หน้าต่างที่สั่งงานมันแทน ไม่ได้เขียนตรรกะใหม่ขึ้นมาอีกชุด ถ้าเครื่องมือเดิมทำงานถูกอย่างไร ตัวนี้ก็ทำงานถูกอย่างนั้น

## ใช้งาน (สำหรับคนพัฒนา — รันจากซอร์สโค้ด)

```
npm install
npm start
```

## สร้างเป็นไฟล์ .exe แจกคนอื่น

```
npm run dist
```

ได้ไฟล์ `dist/Mellow Play Album Sync 1.0.0.exe` — เป็น **portable exe** ไฟล์เดียว ไม่ต้องติดตั้ง ไม่ต้องมี Node.js อยู่ในเครื่องปลายทางเลย (ใช้ตัว Electron เองเป็นตัวรันแทน) ดับเบิลคลิกแล้วใช้ได้ทันที

## หน้าตาการใช้งาน

1. กรอกอีเมล/รหัสผ่านแอดมิน (ใช้บัญชีเดียวกับ CRM) กด **"ทดสอบล็อกอิน"**
2. กด **"เลือกโฟลเดอร์..."** เลือกโฟลเดอร์หลักที่จะใช้ซิงค์ (ข้างในสร้างโฟลเดอร์ย่อยชื่อตรงกับอัลบั้มใน CRM เอง เหมือนเครื่องมือเดิม)
3. กด **"เริ่มซิงค์"**
4. ถ้าใช้ LumaBooth ด้วย ติ๊กช่อง "เชื่อมกับ LumaBooth" เลือกโฟลเดอร์ export แล้วกด **"โหลดรายชื่ออัลบั้ม"** เพื่อเลือกจาก dropdown จริง (ไม่ต้องพิมพ์ชื่ออัลบั้มเอง กันพิมพ์ผิด) แล้วกด **"เริ่มรับรูปจาก LumaBooth"**
5. กด **"บันทึกค่าไว้ใช้ครั้งหน้า"** ครั้งเดียว ครั้งหน้าเปิดโปรแกรมไม่ต้องกรอกใหม่

วางเมาส์ค้างไว้ที่หัวข้อแต่ละช่องจะมีคำอธิบายสั้น ๆ ขึ้นมา

## ความปลอดภัยของรหัสผ่าน

รหัสผ่านที่กด "บันทึกค่าไว้ใช้ครั้งหน้า" จะถูกเข้ารหัสด้วยกลไกของระบบปฏิบัติการเอง (Windows DPAPI ผ่าน Electron's `safeStorage`) ไม่ใช่เก็บเป็นข้อความธรรมดาเหมือนไฟล์ `.env` ของเครื่องมือเดิม — ปลอดภัยกว่า ไฟล์ settings อยู่ที่โฟลเดอร์ข้อมูลของแอปเอง ไม่ใช่ในโฟลเดอร์นี้

## สถาปัตยกรรม (สำหรับคนจะมาแก้โค้ดต่อ)

ตัวนี้**ไม่ได้เขียนตรรกะการซิงค์ใหม่เลย** — มันแค่:
1. เขียนไฟล์ `.env` ให้ `mellow-play-album-sync` ตามค่าที่กรอกในฟอร์ม
2. สั่ง `node src/index.js` / `node src/lumaboothRelay.js` ของเครื่องมือเดิมเป็น child process (ใช้ตัว Electron เองสวมบทบาทเป็น Node ผ่าน `ELECTRON_RUN_AS_NODE=1` — ไม่ต้องมี Node.js แยกต่างหากในเครื่องปลายทาง ทดสอบแล้วว่า `sharp` ซึ่งเป็น native module ก็โหลดได้ปกติด้วยวิธีนี้)
3. ส่ง stdout/stderr ของ child process มาแสดงในกล่อง log ของหน้าต่าง

ถ้าตรรกะการซิงค์ต้องแก้ไข ให้แก้ที่ `mellow-play-album-sync/src/` ที่เดียว ทั้งคนใช้ terminal และคนใช้หน้าต่างนี้จะได้พฤติกรรมเดียวกันทันที

**ข้อจำกัดของสภาพแวดล้อมตอนพัฒนา**: ตรวจสอบหน้าต่าง Electron จริงด้วยการรันโดยตรงในเซสชันนี้ไม่ได้ (ไม่มีจอแสดงผลให้เปิดหน้าต่างจริง) — ส่วนที่ทดสอบจริงคือ (1) ตรรกะหน้าเว็บ (renderer) ในเบราว์เซอร์จริงผ่าน Playwright โดยจำลอง bridge ของ Electron ขึ้นมาแทน (2) การแพ็กเกจเป็น .exe จริงจนสำเร็จ และ (3) `sharp`/`chokidar` โหลดได้จริงผ่านกลไก `ELECTRON_RUN_AS_NODE` ที่ main.js ใช้ ส่วนการเชื่อมต่อ main process ↔ preload ↔ renderer ทั้งระบบเข้าด้วยกันจริง ๆ ยังไม่ได้คลิกทดสอบเองเพราะเปิดหน้าต่างไม่ได้ในเซสชันนี้ — ควรลองรันจริงอีกทีก่อนแจกใช้งานจริง
